Music Genre Prediction Model

A machine learning project built in Python that classifies audio files into music genres. Trained on the FMA-Medium dataset of 25,000 audio clips using MFCC and Chroma feature extraction to convert audio into numerical representations. Implemented and compared a Logistic Regression baseline against a Support Vector Machine (SVM) model, with the SVM significantly outperforming the linear model on high-dimensional audio features.
